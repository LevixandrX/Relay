# UX — стиль «Ice Grid»

Визуальный язык MVP (вместо «Ателье»):

- Холодный светлый фон, сетка, кобальт + мята
- Шрифты: **Unbounded** + **Manrope** (кириллица)
- Лендинг: интерактивное демо-схемы (тянуть блоки, менять инструмент)
- Сайдбар: плавающая тёмная «рейка», сворачивается в иконки, раскрывается по клику/hover

Главный экран после входа — бесконечный холст. На страницах — переключатель Холст/Текст.
