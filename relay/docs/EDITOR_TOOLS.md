# Text editor tools

## References

The catalog follows the interaction model in Notion's [editing guide](https://www.notion.com/help/writing-and-editing-basics): insertion through + or /, block operations through Drag, and contextual actions. [Media](https://www.notion.com/help/images-files-and-media), [tables and layout](https://www.notion.com/help/columns-headings-and-dividers), [equations](https://www.notion.com/help/math-equations) and [code](https://www.notion.com/help/code-blocks) have their own controls.

## Available in Relay

- Text, headings 1–4, bullets, numbers, tasks, quotes, callouts and dividers
- Toggle sections and toggle headings 1–4, with nested editable content and saved open state
- Simple tables: row/column grips, selection and menus, drag reordering, insert/duplicate/clear/delete, cell backgrounds, headers, merge/split, fit to width and column resize
- Images, video, audio, files and PDF: upload/URL, captions and percentage widths
- Web bookmarks and canonical YouTube, Vimeo, Figma and Loom embeds
- Block/inline LaTeX equations with KaTeX and editable source/preview
- Contents generated from current headings, page creation and workspace page links
- Column presets 2–5, existing resizers and layout persistence
- Code hover toolbar: searchable language picker (Enter/Tab), syntax highlighting, copy, saved wrapping/caption and shared block menu
- Compact text selection panel: block type, bold/italic/underline/strike/code, links, inline equations, text/background colors, clear formatting and comments
- Existing comments, colors, block links, duplicate/delete and structural moves
- Explicit list marker formats (bullets, letters and Roman numerals) alongside automatic depth cycles; images/files can also be pasted or dropped

Turn into omits lossy conversions to atomic media/navigation blocks. Slash acceptance deletes the query and replaces the block in one undoable transaction. Table actions use the saved cell selection and omit unavailable commands. Bytes are independent of AST/revisions and follow page permissions.

Table edge buttons add a row/column on click and resize on drag in one undo step. Shrinking stops at nonempty cells. Spanning cells move as structural units; axis duplication is omitted where it would split a spanning cell. Callouts share the first line's handle and use the existing emoji picker. Toggle arrows preserve title/body structure; Enter enters an open body or creates a sibling for a closed section, an empty body exits on Enter, and Backspace unwraps the title without losing its contents. Divider selection and line color use separate paint layers.

All contextual surfaces use Appearance overlay opacity, blur, saturation and radius tokens. Formula editors are viewport-aware popovers with live preview. Nested SVG and math content in controls is handled by the node view, preventing the first click from being consumed by atom selection.

New blocks keep the caret in their title/text or focus the source input. Toggles start closed; Enter in a closed title creates a sibling. Empty tasks show To-do, completed tasks preserve their chosen text/checkbox color, and adjacent backgrounds have separate contours. Code has no prose placeholder; its searchable language list has its own bounded scroll area. More opens beside the toolbar button and suppresses competing block controls.

Callout icons support suggested/recent emoji, random choice, removal, system icons and page-owned image uploads (2 MiB). Callouts reuse the reaction custom-emoji store; Add emoji opens a side panel, icon upload has preview/Save/Cancel and supports pasted files or safe image links. The 102 system icons support search and color, including an ask-every-time preference. Edit icon is available from Drag. Table grips sit on the borders as thin bars and reveal their grip on hover/focus; edge add controls appear near the corresponding edge. The text formatting panel has a separate side conversion menu. Editor tooltips share Appearance styling and shortcuts use explicit plus signs.

Move to (Ctrl+Shift+P) transfers a block to another page in the workspace, preserving list structure, attachments and discussions. Server transfers retain both pages' revisions and reject stale content; guest transfers stage related local data before saving both pages. This cross-page operation is restored through page history rather than the editor's local undo stack.

Discussion geometry is measured in batches only after document/layout changes. The annotation canvas lives in the editor content and scrolls natively with the page: no fixed portal, scroll-position transforms or scroll timeline. Hovering a source only changes its visual emphasis; packing changes on activation or real layout changes. Card movement/hover transitions are suppressed while the page scrolls. Frost uses the same surface backdrop and Appearance tokens, without a card-count cap.

## Separate product systems

Notion also has [databases](https://www.notion.com/help/intro-to-databases), [synced blocks](https://www.notion.com/help/synced-blocks), [buttons/automations](https://www.notion.com/help/buttons), AI/meeting notes and connected app imports. These need models for permissions, references or background actions beyond an individual document node. They are not represented by inert menu entries. The existing web Live Prompt remains available where its execution callback is supplied.

Table selection has a right-edge grip with the same bar-to-handle motion. A caret selects one cell for actions; dragging or Shift-clicking selects a rectangle. Its menu offers text/background colors, merge/split where applicable, comments and clearing, preserving cell structure and undo. Row/column menus use the same color submenu and animated rails; virtual anchors remain attached to table geometry when controls hide. Edge add controls can be reached directly from outside the table. Inline comment buttons are suppressed inside tables.

Code has a compact icon toolbar and a shared keyboard-searchable language popover in both the toolbar and Drag menu. Hover never scrolls the language list; keyboard navigation reveals its active row. Copy, wrap, caption, select and download operate on the code block. Popup height adapts to available space and menus use OverlayScroll with content sizing rather than native scrollbars.

Prose placeholders disappear while editor windows/menus are open. Shortcut Shift/arrows/Enter use SVG key glyphs separated with plus signs; tooltips spell the keys out. Hover targeting ranks a row before its enclosing block and keeps a consistent 32px reach left of its controls at every indentation level.

Drag keeps a mapped bookmark of the original text selection and restores the actual focused DOM caret on dismissal. Temporary NodeSelections never replace the saved writing caret. Page resume resolves the actually scrolling ancestor (skipping unconstrained overflow containers), flushes before navigation, restores scroll before paint and reapplies focus after EditorContent mounts, allowing immediate typing on return or reload.

Callout and reaction pickers share a 360 × 380px footprint; Upload adapts to its contents and the viewport. Emoji sections are memoized and use intrinsic content visibility; category tracking is frame-coalesced. Emoji/Icons use the same rail. Outside click/Escape close the main picker, without a close icon. Empty Callout Upload Cancel closes the picker; a staged image changes it to Back, clearing that image in place. A reaction's Add custom emoji Cancel closes only the child form; its Back clears the image and retains the form. Callout uploads optionally enter the workspace emoji library. Ask every time disables the default palette and opens colored icon variants against the selected icon, with Cancel/Done for custom-color confirmation.

Table controls and selected-cell frames live in the editor's native scroll content. Axis dragging moves a floating copy of one or several selected rows/columns; source text hides while its dimensions and colors remain. The insertion line renders over the copy and the order changes once on release. Spanning cells move as units. Edge/corner resizing updates the document live. One gesture is one undo entry; Escape cancels it. Columns resize independently down to 48px and can extend across the workspace, with horizontal touchpad scrolling and a separate rail below the add-row button. Clear contents stays available for empty cells and resets cell text/background colors too. Axis menus put the header switch first and show existing block edit metadata; selection-only menus stay compact. Help below edges/corner flips above near the viewport boundary. Contextual rails have no arrows and reserve only a small gutter when overflowing.

Conversion, color and list-format submenus open beside the parent without losing its metadata footer. They dismiss when the pointer leaves the trigger/submenu, including parent search and switches; upload forms close by click or Cancel instead. Table row/column/cell operations are grouped into side menus. Hovering the metadata author opens Activity, whose names expose the existing profile. Code omits block Color. Wrap code controls long visual lines, while normal-size captions stay part of the block below its code surface. Code and tables reuse the standard horizontal rail: arrows and centered expansion. The other rail family is compact, without arrows, expanding toward the content. Browser downloads use a connected download anchor; desktop code export uses a native Save dialog through the resource adapter. Copy notices distinguish code, text and block links.

Horizontal rails measure their own track, reserve arrow space and update the thumb directly without rerendering the editor. The outer vertical OverlayScroll permits horizontal input on nested scroll ports; code/table gestures also work over their separate rails. Tables retain a trailing gutter for the column add button; block handles move with the table and clip individually at the canvas edge. Table drag sessions use document pointer listeners and a fixed body-level copy/drop line. While editing a table, collapsed discussion cards that overlap it move below its controls and rail. Expanded discussions stay by their source; selecting annotated text preserves the editor focus and does not reveal/scroll to the card. Table size changes trigger layout measurement, scrolling does not.

The empty callout icon button sits above its text hit area, uses muted control colors and opens the picker at that button. Edit icon from Drag uses the left icon slot. The picker avoids the icon's rectangle. Upload has no URL field: Ctrl+V accepts files or safe image links, with an optional workspace-library checkbox for either source. Reading a linked image for the library uses browser CORS, omits credentials and bounds MIME/bytes/time; a failed read keeps the draft with an error. Custom emoji forms accept clipboard images and focus their visible name input, never a hidden file input. Picker actions share dimensions, hover tokens and presence motion.

Submenus focus their current item and support Right/Left navigation. Menu keyboard focus uses the same neutral fill as pointer hover rather than a second blue outline. Last edited is omitted without recorded metadata; its author opens compact edit/create rows with time and profile access, without a redundant heading. Legacy creation information is omitted when it was never recorded. Existing blocks receive stable identities before insertion so new blocks can record known creation metadata. Cloud page writes in both shells are serialized against the last acknowledged server version; optimistic local timestamps never become a save base. Server conflict checks remain in place for external edits.

Activity tracking and editor identity assignment share the same addressable block types. Structural table rows/cells and toggle parts do not count as unidentified legacy blocks; their presence must not suppress Created for new content. The table NodeView mirrors its block identity and appearance on its wrapper so annotations, tools and page resume can resolve it consistently.

Callout icon pickers prefer the icon's right edge, shift toward the left viewport edge when needed, and fall back to the block edge. Add icon aligns to the block's right edge; Drag Edit icon uses the left icon slot. Every opening starts on Emoji. Emoji/Icons share a search field and square action buttons. Upload and custom emoji accept Ctrl+V with neutral form focus; an explicit Paste image or link button reads the clipboard only after its gesture. Constrained Upload uses OverlayScroll, including previews and library fields. Successful attribute changes focus the changed block without restoring a distant caret. Callout first-line and whole-block comment actions have separate adjacent hit targets.

Table drag copies are constrained to the table and one axis, retain a blue grabbed handle and suppress help while dragging. Full row/column selections qualify as a drag group only on the corresponding axis. Edge add buttons appear from anywhere in the final row/column and clip naturally before the table is fully scrolled to its edge. Code touchpad scrolling uses native scrolling over its port; content padding travels with the code, retaining a trailing inset. Side menus restore focus to their parent on pointer dismissal; root keyboard navigation also works when focus has left its former child, with one active highlight.

Selection formatting waits until the pointer selection ends (110 ms settling), retains its bookmark and follows visible DOM range fragments. Scrolling out hides the panel with an exit transition; returning to any visible fragment restores it. Text/background colors use the shared side palette. Menu chevrons and tooltip glass/radii are shared. Emoji labels use English/Russian Unicode CLDR names (see docs/licenses/UNICODE.txt). Color swatch, HEX and Reset share a 34px control height.

Hover geometry treats container headers and later child rows separately, caches rows until document/layout/scroll changes and includes approach from the comment gutter. The Callout header offers one whole-block Comment action. Child rows use the same page-wide comment gutter; compact indicators share the header/first-line scope and never compete with an Add control. Collapsed cards are checked against all wide tables/columns after stack packing, including cards displaced by earlier cards. Table edges are exclusive in the last cell, with the last movement choosing the row or column edge. Full-table selection paints the actual table width and fades only at a clipped right edge. Code scrolls inside a fixed 24px inset on both sides.

The desktop editor scroll container is not a backdrop root. Page glass paints on the scroll wrapper pseudo-element, so discussion cards can blur editable text and colored block paint with the same Appearance tokens as compact popovers. Annotation geometry remains in native document coordinates. Callout/code frames match the ordinary painted row width; block selection adds a 4px rim (2px inside columns/list items), while tables retain their own overflow-aware paint. The formatting panel has ten controls including anchored More actions and suppresses other editor controls while open. Explicit action anchors retain their geometry when the formatting surface exits.

Shared scrollbar dragging coalesces pointer movement into one immediate scroll write per animation frame, caches size measurements separately, and moves thumbs through compositor translation. Geometry is refreshed on content/size changes instead of reading layout after every pointer movement. Arrow hold also advances per frame. Vertical surfaces consume diagonal horizontal drift without blocking nested code/table scrollports; root pages cannot pan horizontally. Last-cell table edge intent uses a displacement threshold and directional hysteresis.

Selection contours keep a persistent paint surface across addressable blocks, with a short enter/exit transition and no geometry animation. Radius follows Appearance; reduced-motion disables the transition. Callout/code contours include their whole visual frame and code caption. Resizable media paints on its inner frame, not the full-width node wrapper; a hidden caption toolbar overlays media without leaving an empty selected strip. Its handles follow that frame while Comment remains reachable in the ordinary page gutter. Tables keep their independent full-width selection layer and clipped-edge fade through deselection.

Fill and selection contour interpolate through one registered CSS progress value, avoiding compounded opacity/color/shadow transitions and a delayed rim. The text-format color control uses a stroke glyph with a current-color sample. The footer reserves a compact, explicitly unavailable reaction action with a localized coming-soon tooltip; Comment keeps its shortcut in its tooltip.
