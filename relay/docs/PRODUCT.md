# Relay — продуктовый бриф

> **Relay** — пространство для текста и **безграничного холста**: схемы, майндмэпы, рисунки + страницы с блоками.
> Интерфейс MVP — **русский** (английская локаль позже).

## Для кого

Люди и небольшие команды, которым нужны и «страницы как в Notion», и свободный canvas «как в Miro/Excalidraw» — в одном пространстве.

## MVP

- Аккаунты, пространства, роли (`owner` | `editor` | `viewer`)
- **Бесконечный холст пространства** (tldraw): фигуры, стрелки, текст, карандаш, стикеры
- Страницы с блоками + переключатель **Холст / Текст** на каждой странице
- Live Prompt, поиск, публичные ссылки, пульс, онбординг на русском

## Дифференциаторы

1. Холст без краёв как домашний экран пространства
2. Live Prompt по AST страницы
3. Intent-онбординг + чеклист первых шагов

## Принципы UX

1. После входа — сразу холст, не пустой дашборд
2. Подсказки в контексте, без длинных туров
3. Два понятных режима: Холст и Текст
